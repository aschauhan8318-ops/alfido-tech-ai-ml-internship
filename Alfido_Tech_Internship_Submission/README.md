# Alfido Tech AI/ML Internship – Complete Project Package

This repository contains four practical tasks:
1. ML Classification – SMS Spam Detection (scikit-learn)
2. Deep Learning – IMDB Movie Sentiment Analysis (TensorFlow/LSTM)
3. Model Deployment – Flask REST API + Docker
4. Responsible AI – Explainability, error analysis and fairness checks

## Recommended order
Run Task 1 first, then Task 2, then Task 3, then Task 4.
Task 3 and Task 4 reuse the trained model produced by Task 1.

## Requirements
- Python 3.10 or 3.11 recommended
- Git
- Docker Desktop (Task 3 only)
- Internet connection for first-time dataset downloads
- For TensorFlow on Windows, use a compatible Python/TensorFlow version; Python 3.10/3.11 is recommended.

## Folder map
- `Task1_ML_Classification/`
- `Task2_Deep_Learning/`
- `Task3_Model_Deployment/`
- `Task4_Responsible_AI/`
- `Submission_Guide/`

Each task folder has its own README, requirements, runnable scripts, notebook and report template.

## Important
The source code is prepared, but model files, plots and numeric evaluation results are generated when you run the training scripts. Do not submit invented metrics. Run the scripts, review the outputs, and include the actual generated files in your final GitHub repository.
